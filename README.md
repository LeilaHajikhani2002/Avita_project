# Template Project

This is a frontend template project built using HTML, SCSS, JavaScript, and multiple npm libraries.

---

## 🚀 Features

- Responsive layout
- Animations using AOS library
- Image sliders using Slick and bxSlider
- jQuery for DOM manipulation
- SCSS for better styling structure

---

## 📦 Libraries Used (npm)

- aos
- jquery
- slick-carousel
- bxslider

---

## 📁 Project Structure

- css/ → compiled CSS files  
- scss/ → SCSS source files  
- js/ or Scripts/ → JavaScript files  
- html/ → HTML pages  
- images/ → image assets  
- node_modules/ → installed dependencies (NOT uploaded to GitHub)
