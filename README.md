# Avita-Project-info
Live Demo:

🌐 Frontend Project

A responsive and interactive frontend project built with HTML5, CSS3, SCSS, jQuery, AOS, Slick Carousel, and BxSlider.

✨ Features

- 📱 Responsive and mobile-friendly design
- 🎨 Custom styling with SCSS and CSS
- ✨ Scroll animations using AOS
- 🎠 Interactive sliders and carousels
- ⚡ jQuery-based interactions
- 🧩 Modular and maintainable styles

🛠️ Technologies & Libraries

- HTML5 — Page structure and semantic markup
- CSS3 — Custom styling
- SCSS — CSS preprocessor for organized and maintainable styles
- JavaScript — Client-side functionality
- jQuery — JavaScript library for DOM manipulation and interactions
- AOS (Animate On Scroll) — Scroll-based animations
- Slick Carousel — Responsive carousel and slider
- BxSlider — jQuery-based responsive slider
- NPM — Package management

- 📦 Installation

Clone the repository:

git clone https://github.com/LeilaHajikhani2002/Avita_project.git

Navigate to the project directory:

cd project-name

Install the project dependencies:

npm install

🚀 Run the Project

After installing the dependencies, open the project using a local development server.

If you are using VS Code, you can use the Live Server extension to run "index.html".

📝 Notes

This project uses SCSS for styling and several frontend libraries installed through NPM, including jQuery, AOS, Slick Carousel, and BxSlider.
